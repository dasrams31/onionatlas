# OnionAtlas

Landing page directory for a collection of personal Tor hidden services.

Lists: Peka (social), Aeterra (onion provider), Whisper (chat),
Jot (pastebin), Snip (URL shortener).

## Stack

Single static HTML file. No frameworks, no external assets.

## Run

Serve `public/` over HTTP and point a Tor hidden service at it.
